# Maison Smitou — site vitrine de démonstration

Site statique responsive (HTML/CSS/JavaScript), sans compilation ni dépendance locale.

## Prévisualiser
Ouvrir `index.html` dans un navigateur. Les images de démonstration et les polices nécessitent Internet.

## Personnaliser
- `script.js` : renseigner `WHATSAPP_NUMBER` avec un numéro international sans `+`, espaces ni zéros initiaux (ex. `33612345678`). Sans numéro, les boutons WhatsApp sont désactivés.
- `script.js` : remplacer les six produits fictifs par vos vraies robes, photos, tailles et prix.
- `index.html` : adapter les textes de marque et ajouter les informations légales requises avant commercialisation.
- Les photographies chargées depuis Unsplash sont illustratives et ne représentent pas des produits Maison Smitou. Vérifier les droits et utiliser vos propres photos avant commercialisation.

## Publication gratuite sur GitHub Pages
1. Créer un dépôt GitHub public (offre gratuite).
2. Déposer les fichiers `index.html`, `styles.css` et `script.js` à la racine du dépôt.
3. Ouvrir Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Patienter jusqu'à la mise en ligne sur l'adresse GitHub Pages fournie.

Ce site ne collecte pas de données personnelles en lui-même. Les liens WhatsApp ouvrent un service tiers une fois activés. Ajouter les mentions légales et informations nécessaires selon votre situation.
